Story JSON format

Each scene needs an id, the native line, its English translation, an optional audio filename, choices and quizzes. Example:

{
  "title": "My Story",
  "language": "Kikuyu",
  "start": "scene1",
  "scenes": {
    "scene1": {
      "character": "Amina",
      "native": "Wĩmwega?",
      "translation": "How are you?",
      "audio": "myscene1.mp3",
      "choices": [
        {"label": "Ndĩ mwega.", "next": "scene2"}
      ],
      "quizzes": [
        {"question": "What does 'Wĩmwega?' mean?",
         "options": ["How are you?", "Goodbye", "Thanks"],
         "answer": 0}
      ]
    }
  }
}
